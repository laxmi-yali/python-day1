# python-day1

This repository contains 5 basic Python programming problems designed to improve logical thinking and programming skills. These programs help beginners understand loops, conditional statements, and string operations.

📝 Problems Covered

1. Even or Odd Number

Check whether a given number is even or odd.

Concept: if-else

2. Multiplication Table

Print the multiplication table of a number entered by the user.

Concept: for loop

3. Find the Largest Number

Find the largest among three numbers.

Concept: if-elif-else

4. Reverse a String

Reverse a given string using a loop.

Concept: for loop

5. Count Positive and Negative Numbers

Take 10 numbers from the user and count positive and negative numbers.

Concept: for loop and if-else
